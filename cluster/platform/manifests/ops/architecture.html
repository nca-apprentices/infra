Cluster architecture

One Talos node on Hetzner, behind Cloudflare, kept in sync by Argo CD from nca-apprentices/infra. Back to the portal

Request path

  • Cloudflare proxies the apex and *.nca-apprentices.dev to the one node.
  • The firewall admits 80 and 443 from Cloudflare only. Traefik also wants the zone's client certificate.
  • jjforge-prod and ncaleague-prod are public. Dev and previews pass github-login first.
  • Each ops tool has its own host. The ops login signs in through Argo CD's Dex.

GitOps and secrets

  • OpenTofu creates the network, firewall, node, volume, DNS, and buckets.
  • apply:bootstrap installs Cilium and Argo CD. Argo CD owns the cluster after that.
  • root → platform/ → the apps ApplicationSet → one Application per apps/<app>/<env>.
  • SopsSecrets from Git decrypt in the cluster with the age key. The escrow key stays offline.

State, telemetry, and alerts

  • Six stores back up to fsn1: two Postgres clusters, SeaweedFS, Redpanda, metrics, and logs.
  • Apps send OTLP to the Collector. Beyla adds eBPF traces and RED metrics.
  • Alerts open GitHub issues. Watchdog posts a heartbeat to the status Worker.
  • The Worker runs on Cloudflare, so it reports a dead node or alert pipeline.
